PLAYY.Music

PLAYY.Music is a social music platform that combines artist pages, community features, discovery, events, and commerce in one product.

The build spans public landing experiences for music, media, records, and PR campaigns, plus account flows, artist profiles, social feeds, forums, marketplace pages, event purchasing, realtime messaging, and payments.

Vue SPA PR Campaigns Marketplace Events Realtime Messaging
Who It Serves

Independent artists and creators first, with fan, label, and promoter-facing surfaces visible in the product.

Build Overview

Landing pages, profiles, social and forum features, music discovery, PR campaign flows, marketplace pages, and event operations inside one application.

Frontend Architecture

Vue 2.7 SPA with Vue Router, Vuex state, axios-based API wrappers, Stream chat and call integrations, and Stripe payment handling.
